LLM으로 실험 준비
Codex가 실험 코드를 작성하고 Claude가 검토합니다. 승인 후 내장 단위 검사 → 실제 실험 → LLM 결과 분석이 자동으로 이어집니다.
참고 폴더는 읽기만 합니다. 필요한 환경이나 데이터가 없으면 표시합니다. 코드 승인 전에는 실험을 실행하지 않습니다.


연구 시작
논문 탐색 → Council → 실험 설계 → LLM 코드 작성·검토 → 실행 승인 대기. 실제 Claude·Codex 사용량이 발생합니다.
실행 한도
한 번의 Council을 실행합니다. 토큰 예산은 호출 전 추정과 단계별 중지 기준이며, 진행 중인 호출까지 포함한 결제 상한은 아닙니다.
